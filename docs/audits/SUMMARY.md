## What I checked and found sound
- World generation: 360 floors (depth 2-42) → stairs and every monster spawn reachable (0 failures), chute present on all, only `hidden_cache` closets unreachable (by design), generation 1-3 ms; static boss floors are tile/prop/spawn-identical across seeds; no shared mutable state in `pickVariant`.
- Module-level game state (Flow, Heat, embers, wisps, zones, bargains, perk state, controller, lockdown) is reset on every scene change; perk stats are re-derived (idempotent) so apply/un-apply is correct; `timeScale` is restored by timer, real-time fallback, death and scene change.
- Save JSON is plain; transient fields are reset on load; `fit()` pads containers; HUD writes are change-gated; engine pools are real pools; data-reference consistency (bias monster ids, boss ids, build skills, perk plans, unique families, synergies) has zero dangling ids.
- Wren's relic fix is correct (`map.revealed` is minimap-only, explored % stays honest).

## Process recommendations
1. **Release gate:** a headless pre-push run of `tests/run-headless.ps1` (exists, untracked) that also fails on (a) any `src/` change without a `sw.js` VERSION change, (b) syntax/load errors (the last shipped break), (c) missing manifest files. Show the build id in the menu.
2. **Contracts that test shapes, not just names:** keep `contract.json`, but (a) fail on *guarded* calls to non-existent functions (today `canEquip`, `gamblePrice`, `grantMark`, `LOOK_FAMILIES` all pass), (b) add writer→reader fixtures for every shared settings/flags key (`lootFilterRules`, `sellFilter`, `crateBonus`, `loyalty`, `classGoals`), (c) generate the "unused public API" list each run and delete or wire it. Ban "tolerant readers" (`hud.js:807-824`) for first-party payloads: read one shape, warn once in dev when it is missing.
3. **One owner per persisted key**, listed in DESIGN with its shape and a `settingsVersion`/`flagsVersion` + migration table in `meta.js`; add old-save fixtures (one per release) to `tests/all.html` and load them.
4. **Second balance harness:** keep the bot for pacing, add the synthetic best-of-N kit builder used in this audit (levels 20/30/40/50, all classes) to report hits-to-kill per rarity and per boss, and fail the build when a normal monster dies in < 2 hits on on-level gear or a boss in < 20.
5. **Strings:** a lint in `all.html` for raw literals in `h()/toast()/btn()` calls and for characters missing from the bitmap font; extend `docs/WRITING_GUIDE.md` with the full list in ui.md §5 (items, game, world and engine text included).
6. **Device checks:** a `?perf` URL that logs 10 s of frame ms, canvas count and decoded-asset MB to the console, run once per release on the oldest iPhone; the asset pipeline needs it before art lands.
7. **Docs:** fold resolved open questions into DESIGN, correct the SW version line, document the map extras game attaches (`mods`, `_reward`, `revealed`, `pallorUp`), and keep a "new class checklist" (game §5, items §5).
8. **Cross-team change protocol:** a call or event may be used only after it appears in `contract.json`; the xref script used here (grep `G.<ns>.<name>` per directory, check `typeof` at runtime) takes 20 lines and belongs in `all.html`.
